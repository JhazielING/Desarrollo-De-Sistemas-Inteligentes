**Actividad 1.2 Casos de uso de Zabbix**
- **Monitoreo de servidores**  
    Permite revisar CPU, memoria, almacenamiento y rendimiento de servidores para detectar problemas.
- **Monitoreo de redes**  
    Supervisa routers, switches y conexiones para detectar caídas o problemas de comunicación.
- **Monitoreo de páginas web**  
    Comprueba si una página está disponible, cuánto tarda en responder y si presenta errores.
- **Monitoreo de bases de datos**  
    Permite vigilar el rendimiento, conexiones y disponibilidad de bases de datos como MySQL o PostgreSQL.
- **Alertas y detección de fallas**  
    Cuando un equipo o servicio presenta un problema, Zabbix puede enviar alertas para que el administrador actúe rápidamente.
